## 业务背景

职业卫生人员需要从 MSDS（化学品安全技术说明书）中识别职业危害因素，判断是否属于职业病危害范畴。传统方式依赖人工逐页阅读、手动查表，效率低且容易遗漏。

## 解决的痛点

1. **MSDS 页数多、信息散**：一份 MSDS 几十页，关键信息散落在不同章节
2. **专业知识门槛高**：CAS 号匹配、危害因素分类需要专业知识
3. **人工查表效率低**：人工对照知识表逐一判断，耗时且容易出错

## 效果

- **信息提取**：自动定位成分章节，提取 CAS 号、含量、页码
- **知识匹配**：自动匹配职业病危害因素知识表
- **人机兜底**：不确定项自动转人工，不自动出具合规结论
- **安全边界**：明确标注"辅助决策，不替代专业判断"
